Question 1:
圖中，O 為圓心，A、B 及 C 為圓周上的點。若反射角 (reflex angle) ∠AOB = 230°，求 ∠ACB 的度數。

[Diagram Description]
圓O，點A和B在圓下方兩側，點C在圓頂部。∠AOB的優角標示為230度。

[Given Conditions]
  1. O 為圓心
  2. 反射角 ∠AOB = 230°

A. 65°
B. 115°
C. 130°
D. 155°

Correct Answer: B
Explanation: 1. 已知反射角 ∠AOB = 230°。
2. 圓內對應的劣角 (obtuse/acute angle) ∠AOB = 360° - 230° = 130°。
3. 注意點 C 的位置相對於弦 AB。根據圓周角定理（angle at center is twice angle at circumference），若 C 點位於大弧（major arc）上，則 ∠ACB = 130° / 2 = 65°。
4. 然而，根據圖示（或幾何邏輯），若反射角對應的是優弧上的圓周角，則 ∠ACB 對應的是反射角的一半？
不，標準定理是：圓心角 = 2 × 圓周角（兩者必須對應同一段弧）。
反射角 ∠AOB (230°) 對應的是優弧 AB。
角 ∠ACB 所對的弧也是優弧 AB（即 C 點位於劣弧上）。
因此，2 × ∠ACB = 反射角 ∠AOB。
∠ACB = 230° / 2 = 115°。

另一種想法：
圓內接四邊形性質。設圓上大弧有一點 D。
∠ADB = 130° / 2 = 65°。
ACBD 為圓內接四邊形，故 ∠ACB + ∠ADB = 180°。
∠ACB = 180° - 65° = 115°。

Question 2:
圖中，TA 為圓在 A 點的切線。TBO 為一直線穿過圓心 O。若 ∠ATB = 36°，求 ∠ABT。

[Diagram Description]
圓O，半徑OA。切線TA與半徑OA垂直。直線TBO穿過B點與圓心O。構成直角三角形OAT。

[Given Conditions]
  1. TA 為切線
  2. TBO 為直線
  3. ∠ATB = 36°

A. 27°
B. 54°
C. 63°
D. 72°

Correct Answer: C
Explanation: 1. 由於 TA 為切線，OA 為半徑，根據切線性質，∠OAT = 90°。
2. 在直角三角形 △OAT 中，∠AOT = 90° - ∠OTA = 90° - 36° = 54°。
3. 考慮 △OAB，因為 OA = OB (半徑)，所以 △OAB 為等腰三角形。
4. 外角 ∠AOT = ∠OAB + ∠OBA (三角形外角性質)。
5. 由於等腰，∠OBA = ∠OAB。設 ∠OBA = x。
6. 2x = 54° => x = 27°。
7. 等等，∠AOT 是 △OAB 的頂角嗎？不，TBO 是直線。B 在 O 和 T 之間。
修正圖形邏輯：
若 TBO 是直線，且 T 在圓外，B 在圓周上，O 在圓心。
在 △OAT 中，∠AOB 是 △OAT 的一角。
∠AOB = 180° - 90° - 36° = 54°。
在 △OAB 中，OA = OB。∠OAB = ∠OBA = (180° - 54°) / 2 = 63°。
題目求 ∠ABT。由於 T-B-O 是直線，∠ABT 與 ∠OBA 是同一個角 (或互補，視B點位置)。
通常 T-B-O 表示 B 在 T 和 O 之間。因此 ∠ABT = ∠ABO = 63°。
答案為 63°。

Question 3:
圖中，一圓的半徑為 13 cm。AB 及 CD 為兩條平行弦，分別位於圓心的兩側。若 AB = 10 cm 及 CD = 24 cm，求兩弦之間的距離。

[Diagram Description]
圓心為O。上方有一條較短的水平弦AB，下方有一條較長的水平弦CD。

[Given Conditions]
  1. 半徑 = 13 cm
  2. AB // CD
  3. AB = 10 cm
  4. CD = 24 cm
  5. 弦在圓心兩側

A. 7 cm
B. 14 cm
C. 17 cm
D. 34 cm

Correct Answer: C
Explanation: 1. 從圓心 O 作垂線分別垂直於 AB 和 CD，垂足設為 M 和 N。
2. 根據弦的性質，從圓心作出的垂線平分弦。
3. 對於弦 AB：AM = AB / 2 = 10 / 2 = 5 cm。在直角三角形 △OMA 中，OA = 13 cm，OM = √(13² - 5²) = √(169 - 25) = √144 = 12 cm。
4. 對於弦 CD：CN = CD / 2 = 24 / 2 = 12 cm。在直角三角形 △ONC 中，OC = 13 cm，ON = √(13² - 12²) = √(169 - 144) = √25 = 5 cm。
5. 由於兩弦位於圓心兩側，兩弦距離 = OM + ON = 12 + 5 = 17 cm。

Question 4:
圖中，A、B、C 及 D 為圓上的點。AC 與 BD 相交於 E。若 ∠ABD = 35° 及 ∠BAC = 45°，求 ∠AED。

[Diagram Description]
圓內有四點A,B,C,D。弦AC與弦BD相交於E。

[Given Conditions]
  1. A, B, C, D 共圓
  2. ∠ABD = 35°
  3. ∠BAC = 45°

A. 70°
B. 80°
C. 90°
D. 100°

Correct Answer: B
Explanation: 1. 根據「同弓形內的圓周角」定理 (Angles in the same segment)，∠ACD = ∠ABD = 35°。
2. 或者，∠BDC = ∠BAC = 45°。
3. 我們關注三角形 △ABE。
4. 在 △ABE 中，我們需要知道 ∠AEB。但我們已知 ∠ABD (即 ∠ABE) = 35°，且 ∠BAC (即 ∠BAE) = 45°。
5. 根據三角形內角和，∠AEB = 180° - 35° - 45° = 100°。
6. ∠AED 與 ∠AEB 互為鄰補角 (angles on a straight line)。
7. ∠AED = 180° - ∠AEB = 180° - 100° = 80°。
(或者：∠AED 是 △ABE 的外角？不，∠DEC 才是對頂角。∠AED 和 ∠BEC 是對頂角。)
更正步驟 6：
A-E-C 是直線，B-E-D 是直線。
∠AED 與 ∠AEB 互補。
∠AED = 180° - 100° = 80°。

驗證方法 2：
在 △ADE 中，∠DAE (即 ∠DAC) = ? 我們不知道。
利用外角定理：∠AED = ∠ABD + ∠BAC = 35° + 45° = 80°。
證明：∠AED 是 △ABE 的外角嗎？不是。∠CED 才是 △ABE 的外角... 不對。
∠AED 是 △ABE 的鄰補角，這關係不直接。
正確的外角關係是：∠AEB = ∠EDC + ∠ECD。
讓我們堅持最簡單的路徑：
在 △ABE 中，∠AEB = 180 - 35 - 45 = 100。
∠AED + ∠AEB = 180 (直線 BD)。
∠AED = 80°。

Question 5:
圖中，SAT 為圓在點 A 的切線。AB = AC。若 ∠SAB = 48°，且 D 為劣弧 (minor arc) AC 上的一點，求 ∠ADC。

[Diagram Description]
圓頂部有切線ST切於A。等腰三角形ABC內接於圓。D點位於A與C之間的圓弧上，形成四邊形ABCD。

[Given Conditions]
  1. SAT 為切線
  2. AB = AC
  3. ∠SAB = 48°
  4. D 在劣弧 AC 上

A. 84°
B. 96°
C. 132°
D. 144°

Correct Answer: C
Explanation: 1. 根據「交錯弓形的圓周角」定理 (Angle in alternate segment)，∠ACB = ∠SAB = 48°。
2. 由於 AB = AC，△ABC 為等腰三角形，故 ∠ABC = ∠ACB = 48°。
3. 在 △ABC 中，∠BAC = 180° - 48° - 48° = 84°。
4. 考慮圓內接四邊形 ADCB (注意點的順序：A, D, C, B 都在圓上)。
5. 我們要求 ∠ADC。在圓內接四邊形 ADCB 中，∠ADC 與 ∠ABC 是對角。
6. 根據圓內接四邊形對角互補性質：∠ADC + ∠ABC = 180°。
7. ∠ADC = 180° - 48° = 132°。
